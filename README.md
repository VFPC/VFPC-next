# vFPC

vFPC is a C++ plugin for EuroScope that assists VATSIM UK controllers
with the validation of IFR departure flight plans against applicable
UK routing and departure restrictions.

## vFPC 4

vFPC 4 represents a substantial rewrite of the previous vFPC
implementation, with a new architecture designed to improve validation,
reliability and maintainability.

This repository contains the source code for vFPC 4 and later versions.

## Downloads

Released versions of `VFPC.dll` are distributed through the
