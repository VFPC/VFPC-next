# VFPC Guide

vFPC is a EuroScope plugin for UK VATSIM that checks filed IFR departure flight plans against the current VFPC restriction data and shows the result directly in the departure list.

!!! note "Note"

	It is recommended that your Euroscope UK Sector Files and VATSIM UK Controller Pack are current before using vFPC.

## Guides

This user guide is divided into the following sections:

- [Installation and Configuration](installation.md) — installing and configuring vFPC.
- [Using vFPC](using-vfpc.md) — normal operation and viewing validation results.
- [Validation Reference](validation-results.md) — result codes and how to interpret them.
- [Troubleshooting and Limitations](troubleshooting.md) — common problems and known limitations.
- [Reporting Issues](reporting-issues.md) - getting support and reporting issues.

!!! warning "Controller Responsibility"

    vFPC is a controller aid, not a clearance engine.  It is an assistive validation tool and is not a substitute for controller knowledge or judgement. Controllers remain responsible for understanding applicable departure procedures, SID restrictions, flight level capping and the semicircular rule.
