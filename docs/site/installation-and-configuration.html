VFPC Plugin Documentation

Installation and Configuration

VFPC is no longer included within the UK Controller Pack. It is distributed separately and must be installed and configured in EuroScope before use.

On this page

  1. Download
  2. Plugin configuration
  3. Departure list configuration

Download

VFPC can be downloaded from the latest VFPC release.

Once you have downloaded vfpc.dll, move it to the recommended EuroScope plugin folder: 

%APPDATA%\EuroScope\UK\Data\Plugin\VFPC\

Plugin Configuration

Before you use the plugin, it needs to be configured within EuroScope as follows:

  1. Start EuroScope and select a profile file (.prf).
  2. From the menu bar, select Other Set → Plug-ins.
  3. In the Plug-ins dialog, click Load and navigate to the folder where you moved vfpc.dll.
  4. Select vfpc.dll and click Open.
  5. vfpc.dll should now appear in the list.
  1. Select vfpc.dll within the plugin list.
  2. Within Forbidden to draw on types, select Standard ES radar screen.
  3. Click the double left angled brackets (<<) to move Standard ES radar screen into the Allowed to draw on types list.
  4. Repeat the same process for SMR radar display.

Departure List Configuration

The final part of configuration is to add a column to the Departure List. This column displays the VFPC validation results.

  1. Click S in the top left of your Departure List to open the Departure list columns setup dialog.
  1. Click Add Item. This should add a new item called Callsign to the bottom of the list.
  2. Select the new item and use the dropdown to change Tag Item Type to VFPC/VFPC.
  3. Configure the display options for the new column. Recommended settings are:
    • Header name: FPL
    • Width: 4
    • Align to center: off / unchecked
  4. Set the Left button action to VFPC (UK) / OPTIONS.
  5. Set the Right button action to UK Controller Plugin / Open SRD Search.

The VFPC plugin is now configured and ready for use.

Tip

You can move the position that the FPL column appears on the Departure List by using the Item Up and Item Down buttons.
